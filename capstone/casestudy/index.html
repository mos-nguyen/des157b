Project Overview

My capstone project is a narrative "visual novel" style game that takes place where censorship has gone further than necassary. You play as a fox detective named Fennek who must solve a murder mystery, but unfortunately all the important clues have been censored to protect innocent eyes.

Project Research

Screenshot of TikTok post using "unalive" in place of "suicide"

Censorship is something that I dont think about often. It happens so often on social media that I feel as though Ive become desensitized by it. Censorship of words, gore, sexuality, are all examples Ive seen. When starting this project, I didn't know what topic I would choose until I watched a video online where they censored the word "kill" as "unalive".

This is a common occurance, especially on social media sites like TikTok where videos can be taken down for using the wrong word. The censoring of words and topics like this have always bothered me, so I began to wonder what would happen in the future if censorship continued like this.

When looking into research for censorship, I first thought about entertainment. The Hays Code as well as 1984 by George Orwell was what I thought about with the Hays Code censoring entertainment, and 1984 being a form of entertain about censoring.

Visual Design

The first iteration of the background. It was done quickly and crudely as a placeholder while I figured out the CSS for the game background. Once I had a deeper understanding of how I would format the game, I looked up references of alleyways and deadends to give myself ideas.

This is what the final background ended up as. I decided I wanted more room to focus on where all the evidence would go so it wouldnt feel too crowded. I used basic shapes and icons on Figma to create a loose format on where I wanted each item to go, and used that as reference for where the ground should go for the background. It also helped with the placement of items later on.

A side by side of the first character sketch for Detective Fennek and his final look. Being the first character I worked on meant he would be setting the style and theme for the rest of the characters. I went into his design wanting a noir detective aesthetic which I looked up images to use as inspiration. After seeing the style, I looked up clothing that matched the images I liked as well as looked for images of foxes since I was unfamiliar with drawing animals.

User Interface

Earlier iterations of my project had the game take up the entire viewport which not only made it difficult to position images, but it made it very jarring to look at as well. It looked ok on smaller screens, but bigger screens made everything feel too out of proportion. The character also blended in far too much when speaking, but I didn't want to change the values of the characters or the background too much.

To deal with this issue, I have the character dialogue screen a slightly transparent dark background similar to the overlays I had.This way, the background and user interface could still be seen, but the focus is on the characters currently speaking.

The red was a choice I made to have certain important parts of the interface pop out more. I wanted everything else to be black and white to fit with the noir aesthetic, but red would be used to disrupt and catch the players attention. It also tied in with the blood so it didn't feel too out of place.

Revisions

Usability testing could have been more useful had I gotten more of the project finished at the time. Despite that, I still had some good feedback. Without much to do, I observed players click out to explore, seeing if there was anything they missed. A reoccuring issue was that people would click on the door icon, not knowing that it would send them back to my Portal page. To fix this, I wanted to add labels or a warning of what it would do, but due to timing I ended up explain what each of the icons did in the beginning overlay.

A concern I also had was whether characters would easy to tell apart. Since there were only two characters at the time, players didnt have a hard time telling who was talking. When I added more, I decided to keep them as separate dialogues so theres no mix up.

This was also easier for me to code so I could get more of the content I wanted the player to experience.

Having more time on this project I think I would want to start over, at least with formating the code. Theres a lot of repetition and unorganized code which made everything harder and more confusing to fix. I would definetly try and work in separate parts first to keep myself from getting overwhelmed.

Summary

I learned that I need to work on organization and research when going into such a big project like this one. I am the sort of person that dives right into a project because planning makes me hesitate. The unfortunate side effect of this is that I often end up changing half my ideas half way through, eating up time that could be spent working on the actual project.

The most challenging thing about this project was the time I had to work on it along with having other work to focus on. I often found myself putting off the work because I was studying for other classes or tired from staying up late. I also found that the speed of the quarter system made it all more frustrating since I felt like I would catch up to content that we'd done months ago. Trying to keep up while making sure I understood and remembered past content was frustrating, but I kept going regardless.

As frustrating as using HTML, CSS, and JS is for me, I still enjoyed the feeling of creating something from scratch. I have never been the type to work with computers. I stayed away from anything digital because it all seemed too complicated for me. Im proud of myself for not giving up and instead making something that I can show my family and friends, saying "I made this". Im also pleased that this is something I want to continue learning and get better at, which I plan to do so over the summer.
